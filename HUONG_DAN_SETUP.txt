1. MỞ MÔI TRƯỜNG

Từ PowerShell tại gốc repo:
  & "$env:SystemRoot\System32\WindowsPowerShell\v1.0\powershell.exe" -ExecutionPolicy Bypass -File .\scripts\enter-lab.ps1

Lệnh này mở Ubuntu-24.04 WSL2 tại đúng thư mục và kích hoạt .venv/core.
Python Windows không dùng để chấm Part 6 vì thiếu SIGTERM kiểu Linux.
Kiểm tra trong terminal Ubuntu:
  python --version
  python -c "import os; print(os.name)"
  docker info --format '{{.ServerVersion}}'
  docker compose version
os.name phải là posix. Docker Desktop cần đang mở.

Môi trường riêng tránh xung đột Pydantic:
  .venv/core          Part 1, 2, 4 develop, 5, 6, 7 develop.
  .venv/gateway       Part 4 production (requirements đòi Pydantic >= 2.11).
  .venv/observability Part 7 production nếu chạy Python trực tiếp.
                     Docker tự cài requirements trong image, không dùng venv host.

Mở terminal riêng cho Part 4 production:
  & "$env:SystemRoot\System32\WindowsPowerShell\v1.0\powershell.exe" -ExecutionPolicy Bypass -File .\scripts\enter-lab.ps1 -Profile gateway

Trong Ubuntu, từ gốc repo, có thể đổi môi trường:
  source .venv/core/bin/activate
  source .venv/gateway/bin/activate
  source .venv/observability/bin/activate

Cài lại thư viện và tạo file cấu hình local còn thiếu:
  bash scripts/setup-wsl.sh
Script giữ nguyên file .env đã có, không in secret. Các venv là Python Linux.
